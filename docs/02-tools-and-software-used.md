# 02-Tools and Software Used

- **VirtualBox** : Virtualization platfor hosting the client VM
- **Windows 11** : Client VM OS (Pro edition required for RDP host capability)
- **Remote Desktop Protocol (RDP)** : Native Windows remote access
- **AnyDesk** : Third-party remote support tool, configured for unattended access
- **TeamViewer (Full client)** : Technician side
- **TeamViewer QuickSupport** : no install, no-account cient-side tool and ad-hoc sessions.
**Sysinternals Autoruns** : Advanced startup/autostart diagnostic utility.
