# Remote-IT-Support-Helpdesk-Simulation-Lab

A homelab project simulating real-world IT support tickets using **RDP**, **AnyDesk**, and **TeamViewer**, built in VirtualBox. Created to demonstrate practical helpdesk/IT support troubleshooting and remote-access tooling skills for an IT support/Helpdesk role.

---

## Overview

This project simulates a small-scale remote support workflow: a "client" machine (a VirtualBox VM) develops common IT issue, a "technician" (the host PC) diagnoses and resolves them remotely the way a real helpdesk ticket would be handled. Three separate remote access tools were used across three different support cases to demonstrate breadth if  tooling, not just one workflow repeated.

The goal isn't just "I can fix a printer", it's to show the full support loop; **ticket** -> **remote connect** -> **diagnose** -> **verify** -> **communicate back to user**, which is what the job actually looks like day to day.

## Objectives

- Simulate realistic helpdesk tickets covering different problem categories (networking, services/peripeherals, and system/startup performance)
- Practice both **unattended remote access** (RDP, AnyDesk) and **attended/ad-hoc remote access** (TeamViewer QuickSupport).
- Docuent a professional support workflow, including diagnosis reasoning, not just the fix.
- Produce a portofolio place demonstrating tools genuinely common in the Indonesian IT support market (Windows environment, AnyDesk, TeamViewer, RDP).
